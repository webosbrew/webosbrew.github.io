# Rules

What gets a submission rejected, whatever else is right about it.

{{> stub }}

1. **No AI slop.** An app written mostly by AI, submitted without real human development,
   testing and review, gets rejected. You may use AI tools, but you answer for the code,
   and you have to disclose that use in the pull request.
2. **No piracy.** Nothing that breaks DRM, and nothing that helps with piracy. For IPTV,
   only legal services.
3. **Respect the hardware.** A TV is expensive. Do not risk breaking it.
4. **Honour the licence.** Porting someone else's project means following its open source
   licence.

[apps-repo](https://github.com/webosbrew/apps-repo) holds the current wording. It wins if
this page falls behind.

## Report an Inappropriate Application

If a listed app breaks any of these,
[open an issue](https://github.com/webosbrew/apps-repo/issues/new/choose) and pick the
template that fits.
